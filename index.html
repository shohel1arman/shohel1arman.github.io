~/about

Educator first, researcher always

I'm an Assistant Professor in the Department of Software Engineering at Daffodil International University, where I've taught since 2017, and Lab In-Charge of the DIU Data Science Lab since 2022. Since 2024 I've also been a Research Assistant at the School of Information Technology, Washington University of Science & Technology (USA), working in computer vision, machine learning, LLMs, and NLP within international collaborations.

My research builds and evaluates machine-learning systems for real-world, high-stakes problems. The thread running through it is rigorous evaluation — designing benchmarks and stress-tests that reveal when models genuinely work rather than only appearing to. I've applied deep learning across healthcare, agriculture, and cyber-security, and my current aim is trustworthy and secure AI: models and evaluation methods robust enough for safety-critical deployment.

In the classroom I'm an advocate of hands-on, data-driven learning. Theory matters, but I want every student to leave a session having built something.

Benchmarking LLM code generation

Leading the design of benchmarks that evaluate the reliability of large-language-model code generation. Collaborative research; manuscript in preparation.

2026 — present · python

Remediation value of AI security reports

An execution-grounded benchmark measuring whether an AI-generated security report actually helps a separate fixer repair the vulnerability — judged by whether a real exploit stops firing without breaking the code. Under anonymous review.

2026 · python · manuscript submitted

Cost-efficient agentic evaluation

An empirical study on lowering the cost of stochastic, SWE-bench-style agentic evaluation via non-uniform run allocation — showing that oracle savings of up to ~5× in tokens are not realizable at practical budgets. Manuscript in preparation.

github → agentic-eval-variance

Plant-cell ultrastructure segmentation

A computer-vision system that segments etioplasts and their sub-organelles, computes geometric metrics, infers parent–child organelle relationships, and generates LLM-based biological summaries. Collaborative research.

2025 — present · django · yolov8 · opencv · scikit-image

RodexAI — LLM-integrated road inspection

An end-to-end system pairing object detection (YOLOv8/11/12, Faster R-CNN) with LLM-based report generation, converting road-surface imagery into structured defect reports.

2025 — 2026 · ultralytics · pytorch

BanglaRegionalTextCorpus

A curated dataset of regional Bangla dialects paired with standard-Bangla and English translations, supporting dialect NLP and machine translation. Built with bangla.ai.
